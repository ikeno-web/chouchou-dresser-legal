プライバシーポリシー

最終更新日: 2026年6月7日 / 事業者: NextCore Consulting

1. 基本方針：ローカルファースト

本アプリは ローカルファースト の設計です。利用者の入力データ（化粧品の情報、開封日、Look、肌コンディション、写真、設定など）は 利用者の端末内のみに保存 され、当社のサーバーには送信されません。アカウント登録もありません。

端末内のデータベースは SQLCipher による AES-256 暗号化 で保護されており、暗号鍵は Android Keystore（OS の保護領域）に保管されます。

2. 当社が収集しない情報

  • 氏名、メールアドレス、電話番号、住所などの直接的な個人情報
  • アカウント情報（本アプリにはサインアップ機能がありません）
  • 位置情報
  • 連絡先、SMS、通話履歴、マイク音声、動画ファイル
  • 利用者がアプリ内で入力したいかなる情報（化粧品名、写真、ブランド名、開封日、Look、肌コンディション、設定など）

3. 外部サービスへの送信が発生する場合

以下のケースでは、最小限のデータが外部に送信されます。送信内容は 利用者が明示的に操作したタイミングのみ で、自動送信は行いません。

3.1 Yahoo! ショッピング JAN 照会（任意）

利用者がバーコード読取後に「製品名を照会する」ボタンを 明示的にタップした場合のみ、Yahoo! ショッピング API に JAN コード（数字13桁）のみ を送信します。氏名・端末識別子・位置情報・写真等は送信しません。

提供元ヤフー株式会社（Yahoo! ショッピング Web API）
送信先https://shopping.yahooapis.jp/ShoppingWebService/V3/itemSearch
送信内容JAN コード（13桁の数字）と当社の Yahoo Client ID
受信内容製品名（公開情報のみ）

ヤフー株式会社のプライバシーポリシーが適用されます： https://privacy.yahoo.co.jp/

3.2 広告配信（無料版）

無料版では画面下に AdMob 広告バナーを表示します。当社は 行動トラッキング配信を無効化（NPA: Non-Personalized Ads）しており、当該端末のコンテキストに依存しない汎用広告のみを表示します。

提供元: Google LLC（AdMob）。Google のプライバシーポリシー： https://policies.google.com/privacy

4. 権限の利用目的

権限用途任意性
カメラバーコードスキャン、化粧品写真の撮影任意（拒否でも基本機能は使えます）
写真ライブラリ化粧品写真の選択、シェア画像の保存任意

本アプリは以下の権限を 要求しません：マイク音声、動画、位置情報、連絡先、SMS、通話履歴、ストレージ全体、画面オーバーレイ。

5. データの保管・削除

  • 入力データはすべて端末内 SQLCipher 暗号化 DB に保存されます。
  • 利用者は 「設定 → データ管理」 から、いつでも全データを 物理削除（復元不能） できます。
  • アプリをアンインストールすると、端末内のデータは Android OS の規約に従い削除されます。
  • 当社サーバーには利用者データを保持していないため、当社側からの削除要請は不要です。

6. バックアップに関する注意

  • 利用者は 「設定 → バックアップ」 から、暗号化された .ccdb ファイルをエクスポートできます。
  • バックアップは 利用者が設定したパスワードで PBKDF2 + AES-256-GCM 暗号化 されます。
  • パスワードを失念した場合、当社を含め復号は不可能 です。利用者ご自身でパスワードを安全に保管してください。

7. 子どもに関する事項

本アプリは 18 歳以上の利用者を主な対象とします。13 歳未満の児童の個人情報を意図的に収集することはありません。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本アプリ内（設定 → プライバシーポリシー）またはストア掲載ページにて改訂版を掲示します。
